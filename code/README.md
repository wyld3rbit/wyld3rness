# wyld3rness

The governance harness for autonomous on-call agents: the eval gate that scores an agent's answers before a change ships, the attested CI gate, and tracing with cost for every run. It never imports the agent it governs.

This is the package's own description. The guide is [docs/harness.md](../docs/harness.md), and the project starts at the [root README](../README.md).
